# SafeClip 실시간 녹화 및 이벤트 영상 설계

작성일: 2026-08-25

## 1. 목적

SafeClip에 휴대폰을 전방 블랙박스처럼 사용하는 `실시간 녹화` 화면을 추가한다.
녹화 중 화면 버튼 또는 블루투스 리모컨을 누르면 해당 시점의 앞 1분과 뒤 1분을 합친 이벤트 영상을 별도로 보존한다.

이번 구현은 기존의 블랙박스 영상 가져오기 및 제출 흐름과 분리한다. 사용자가 직접 시작한 경우에만 녹화하고, 녹화 화면을 벗어나면 녹화를 종료한다. 백그라운드 녹화, 자동 사고 판단, 후방 카메라 연결은 이번 범위에 포함하지 않는다.

## 2. 사용자 경험

### 2.1 진입

- 홈 화면에 `실시간 녹화` 진입 항목을 추가한다.
- 진입하면 녹화 전 미리보기와 설정을 표시한다.
- 녹화 화면에 들어간 동안만 화면 방향을 가로로 고정한다.
- 다른 화면으로 돌아가면 기존 화면 방향 설정으로 복원한다.

### 2.2 녹화 설정

- 화질은 기기가 지원하는 범위에서 `FHD 30fps`, `HD 30fps`, `SD 30fps`를 제공한다.
- 기본값은 기기가 지원하는 가장 높은 화질이며 최대값은 FHD로 제한한다.
- 선택한 화질을 지원하지 않으면 바로 아래 지원 화질로 내려가고 사용자에게 표시한다.
- 음성 녹음은 켜기/끄기 설정을 제공하며 기본값은 켜짐이다.
- 마이크 권한을 거부해도 영상 전용 녹화는 허용한다.

### 2.3 녹화 중 화면

- 녹화 시작/종료, 이벤트 저장, 경과 시간, 현재 화질, 음성 상태, 남은 저장 공간을 표시한다.
- 녹화가 시작되면 화면 밝기를 낮추고 화면 꺼짐을 방지한다.
- 녹화가 끝나거나 화면을 벗어나면 밝기와 화면 꺼짐 정책을 원래대로 복원한다.
- 녹화 상태가 명확히 보이도록 빨간 녹화 표시와 경과 시간을 항상 표시한다.
- 녹화 중 뒤로 가기 또는 앱 화면 이탈을 시도하면 녹화 종료 안내를 표시하고 안전하게 현재 조각을 마감한다.

### 2.4 이벤트 저장

- 화면의 `이벤트 저장` 버튼과 지원되는 블루투스 리모컨 키는 같은 동작을 한다.
- 이벤트 시각을 `T`라고 할 때 최종 영상 범위는 가능한 한 정확히 `T-60초`부터 `T+60초`까지다.
- 버튼을 누른 직후에는 `뒤 60초 기록 중` 상태를 표시한다.
- 뒤 60초가 확보되면 조각을 자르고 이어 붙인 뒤 `DCIM/SafeClip`에 최종 영상을 공개한다.
- 녹화가 `T+60초` 전에 종료되면 확보된 범위까지만 저장하고 `2분보다 짧게 저장됨`을 알린다.
- 이벤트 생성 중에도 일반 녹화는 계속한다.
- 3초 이내 반복 입력은 리모컨의 길게 누르기나 키 반복으로 보고 한 번만 처리한다.
- 3초 이후의 입력은 별도 이벤트로 처리하며, 서로 겹치는 이벤트도 순서대로 생성할 수 있다.

## 3. 저장 위치와 파일 정책

### 3.1 사용자에게 보이는 파일

SafeClip이 새로 만드는 최종 미디어는 모두 다음 위치에 저장한다.

`내부 저장소/DCIM/SafeClip`

- 이벤트 영상: `SC_EVENT_yyyyMMdd_HHmmss.mp4`
- 음성 제거 사본: `SC_EVENT_yyyyMMdd_HHmmss_MUTED.mp4`
- 앱에서 저장한 프레임 이미지와 향후 생성 미디어도 같은 앨범을 사용한다.
- 기존 `Movies/SafeClip Captures`, `Pictures/SafeClip Captures`, 사용자가 선택한 이벤트 폴더의 파일은 자동 이동하지 않는다.
- 블랙박스 원본 폴더를 사용자가 Storage Access Framework로 선택하는 기존 기능은 그대로 유지한다.

Android 10 이상에서는 MediaStore의 `RELATIVE_PATH`를 `DCIM/SafeClip`으로 지정한다. Android 9 이하에서는 `WRITE_EXTERNAL_STORAGE` 권한을 Android 9 이하에만 선언하고 런타임 허용 후 같은 공개 폴더에 저장한다.

### 3.2 순환 녹화 조각

- 녹화 원본은 1분 단위 MP4 조각으로 앱 전용 저장소에 둔다.
- 이 조각은 갤러리와 일반 파일 목록에 노출하지 않는다.
- 최근 3시간에 필요한 조각만 보관하고 오래된 조각부터 삭제한다.
- 이벤트 생성에 필요하거나 생성 중인 조각은 삭제 대상에서 잠시 보호한다.
- 앱이 비정상 종료된 뒤 다시 시작하면 미완료 조각을 정리하되 이미 공개된 이벤트 파일은 삭제하지 않는다.
- 새 조각을 만들 수 없을 정도로 저장 공간이 부족하면 오래된 비보호 조각을 먼저 정리한다. 그래도 공간이 없으면 현재 녹화를 마감하고 사용자에게 알린다.

## 4. 기술 구조

### 4.1 모듈 경계

다음 책임을 분리한다.

- `LiveRecordingScreen`: 미리보기, 설정, 녹화 상태, 이벤트 버튼을 표시한다.
- `LiveRecordingViewModel`: 권한, 화면 상태, 녹화 시작/종료, 이벤트 요청을 조정한다.
- `RecordingSessionController`: CameraX 녹화 세션과 1분 조각 회전을 관리한다.
- `RollingSegmentRepository`: 조각 목록, 보존 시간, 보호 상태와 정리를 관리한다.
- `EventClipAssembler`: 이벤트 범위에 겹치는 조각을 선택하고 정확한 범위로 잘라 결합한다.
- `SafeClipMediaPublisher`: 완성 파일을 `DCIM/SafeClip` MediaStore 앨범에 게시한다.
- `RemoteKeyHandler`: 녹화 화면에서만 리모컨 키를 이벤트 요청으로 변환한다.

기존 `MainActivity`가 모든 카메라와 파일 처리 로직을 직접 소유하지 않도록 한다. 화면 전환 연결만 기존 내비게이션 구조에 맞춘다.

### 4.2 카메라와 인코딩

- 카메라 미리보기와 녹화는 CameraX `Preview`와 `VideoCapture<Recorder>`를 사용한다.
- `QualitySelector`는 FHD, HD, SD 순서로 지원 여부를 확인하며 UHD는 선택하지 않는다.
- CameraX가 제공하는 기기별 인코딩 프로필을 사용해 MP4로 기록한다.
- 1분마다 현재 녹화를 마감하고 다음 조각을 시작한다.
- CameraX 조각 전환에는 짧은 영상 공백이 생길 수 있으므로 실제 기기에서 경계 손실 시간을 측정한다. 반복 시험에서 1초를 초과하는 공백이 생기면 출시 전에 직접 MediaCodec 방식 또는 장시간 단일 녹화 방식으로 재검토한다.

### 4.3 이벤트 조립

- 이벤트 기준 시각은 시스템 벽시계가 아니라 녹화 세션의 단조 증가 시간을 사용한다.
- 각 조각에 세션 시작/종료 시각과 파일 URI를 기록한다.
- Media3 Transformer의 `EditedMediaItem`, `EditedMediaItemSequence`, `Composition`을 사용해 첫 조각과 마지막 조각을 자르고 중간 조각을 연결한다.
- 완성 파일을 임시 위치에 만든 뒤 성공했을 때만 MediaStore에 게시한다.
- 조립 실패 시 원본 조각의 보호를 해제하기 전에 재시도 가능 상태와 오류 원인을 남긴다.

### 4.4 음성 제거

- 영상 상세 화면에서 `음성 제거 사본 만들기`를 제공한다.
- 원본은 수정하거나 삭제하지 않는다.
- Media3 Transformer에서 오디오 트랙을 제거해 `_MUTED.mp4` 사본을 같은 폴더에 만든다.
- 처리 중 진행 상태를 표시하고 성공 또는 실패를 명확히 알린다.

## 5. 블루투스 리모컨

- 리모컨 연결과 페어링은 Android 시스템 설정에서 수행한다.
- 앱은 별도 Bluetooth 스캔이나 연결 권한을 요청하지 않는다.
- 녹화 화면이 활성 상태이고 실제 녹화 중일 때만 `KEYCODE_VOLUME_UP`, `KEYCODE_VOLUME_DOWN`, `KEYCODE_CAMERA`를 이벤트 키로 처리한다.
- 해당 화면 밖에서는 볼륨 키의 기본 동작을 방해하지 않는다.
- 설정에 `리모컨 테스트` 기능을 두어 수신된 키와 지원 여부를 표시한다.
- 기기마다 전송하는 키가 다르므로 모든 셀카 리모컨의 동작을 보장한다고 표시하지 않는다.

## 6. 권한과 개인정보 보호

- 카메라 권한은 녹화를 시작할 때 요청한다.
- 마이크 권한은 음성 녹음을 켠 상태에서 녹화를 시작할 때 요청한다.
- Android 9 이하의 공개 폴더 저장 권한은 해당 버전에서만 요청한다.
- 사용자의 명시적인 녹화 시작 없이 카메라나 마이크를 실행하지 않는다.
- 이번 버전은 포그라운드 서비스와 백그라운드 녹화를 사용하지 않는다.
- 녹화 파일은 자동 업로드하지 않으며 기존 제출 화면에서 사용자가 선택한 경우에만 전송한다.
- Google Play 데이터 보안 및 권한 설명에는 카메라, 선택적 음성 녹음, 기기 내 영상 저장과 사용자가 요청한 제출 동작을 실제 구현과 일치하게 반영한다.

## 7. 상태와 오류 처리

주요 상태는 다음과 같다.

- `Ready`: 미리보기와 설정을 사용할 수 있음
- `Preparing`: 카메라와 저장소 준비 중
- `Recording`: 순환 녹화 중
- `EventPending`: 뒤 60초를 확보하는 이벤트가 있음
- `Exporting`: 이벤트 영상 또는 음성 제거 사본 생성 중
- `Stopping`: 현재 조각을 안전하게 마감 중
- `Error`: 권한, 카메라, 인코더, 저장 공간 또는 파일 처리 오류

복수 이벤트가 있으면 녹화 상태와 별개로 각 이벤트 작업의 대기, 조립, 완료, 실패 상태를 목록으로 관리한다. 앱은 처리 중인 작업을 숨기지 않고 완료될 때까지 진행 표시를 유지한다.

## 8. 구현 범위

### 포함

- 홈에서 실시간 녹화 화면 진입
- 녹화 화면만 가로 고정
- 기기 지원 범위 내 최대 FHD 30fps 설정
- 선택 가능한 음성 녹음
- 1분 조각과 3시간 순환 보관
- 화면 버튼 및 리모컨 이벤트 저장
- 앞뒤 1분 이벤트 MP4 생성
- `DCIM/SafeClip` 고정 저장
- 이벤트 영상 미리보기와 기존 제출 흐름 연결
- 원본을 유지하는 음성 제거 사본 생성
- 화면 어둡게 하기와 화면 켜짐 유지

### 제외

- 화면을 끄거나 다른 앱을 사용하는 동안의 녹화
- 서비스가 자동으로 다시 시작하는 상시 녹화
- 후방 USB 카메라 또는 무선 카메라 입력
- 자동 사고 감지와 자동 신고
- 클라우드 실시간 업로드
- 기존 SafeClip 파일의 자동 이전

## 9. 검증 기준

### 자동 테스트

- 이벤트 시각과 조각 메타데이터로 정확한 입력 파일과 자르기 범위를 선택한다.
- 3초 이내 반복 키 입력은 하나의 이벤트만 만든다.
- 3시간보다 오래된 비보호 조각만 삭제한다.
- 보호된 조각은 이벤트 작업이 끝날 때까지 삭제하지 않는다.
- 지원하지 않는 FHD 선택은 HD 또는 SD로 안전하게 대체된다.
- 파일 이름과 `DCIM/SafeClip` 경로가 규칙대로 생성된다.
- 화면 이탈 시 녹화 종료와 밝기 복원이 호출된다.

### 실제 기기 시험

- 현재 개발 기기와 다른 제조사 휴대폰에서 글자와 버튼이 밝은/어두운 테마 모두 보인다.
- FHD 30fps 30분 이상 녹화에서 발열, 중단, 파일 손상을 확인한다.
- 1분 경계 전후 이벤트를 저장해 영상과 음성 공백을 측정한다.
- 리모컨 짧게 누르기와 길게 누르기의 중복 방지를 확인한다.
- 마이크 허용, 거부, 녹음 끄기 각각에서 결과 파일을 재생한다.
- 저장 공간 부족, 카메라 사용 중 충돌, 앱 화면 이탈 시 안전하게 종료되는지 확인한다.
- 생성한 이벤트와 음성 제거 사본이 갤러리 및 SafeClip의 `DCIM/SafeClip` 목록에 나타나는지 확인한다.
