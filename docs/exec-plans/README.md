# exec-plans

Execution plans live here.

This is the main working-history folder. Use it to keep track of planned work, changes made during implementation, and why the plan changed.

Do not erase useful history when a plan changes. Prefer entries like:

```md
## Changed on YYYY-MM-DD

- Previous plan:
- New plan:
- Reason:
- Files affected:
```

Each plan should make it possible to tell whether a problem came from the original plan, a later change, or an implementation mistake.
