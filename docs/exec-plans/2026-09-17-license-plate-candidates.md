# 번호판 후보 분석

## 목적

실시간 녹화 중 이벤트 버튼 또는 리모컨 키를 누르면 버튼 전후의 제한된 프레임에서 번호판처럼 보이는 문자열을 찾아 사용자의 확인을 돕는다.

## 동작 범위

- 영상 이벤트 저장은 기존 방식 그대로 진행한다.
- 분석 프레임은 기기 메모리에 짧게 보관하며 서버로 전송하지 않는다.
- 한국어 ML Kit OCR을 기기 내에서 실행한다.
- 반복 인식, 선명도, 프레임 크기, 버튼 시점과의 거리를 이용해 후보를 정렬한다.
- 가장 좋은 전체 프레임과 번호판 후보 영역을 `DCIM/SafeClip`에 별도 사진으로 저장한다.
- 결과는 최대 3개의 **인식 후보**로 표시하며 확정값으로 취급하지 않는다.
- OCR 실패나 CameraX 분석 미지원은 녹화 및 이벤트 영상 저장을 중단시키지 않는다.

## 제한 및 개인정보

- 흐릿한 숫자를 생성하거나 보정해서 추측하지 않는다.
- 자동 신고, 법규 위반 판단, 차량 소유자 식별을 하지 않는다.
- 사용자가 후보를 직접 확인한 뒤에만 제출 자료로 사용한다.
- 초기 버전은 일반적인 `숫자 2~3자리 + 한글 + 숫자 4자리` 형식을 대상으로 한다.

## 검증

- 번호판 문자열 추출과 오탐 방지 단위 테스트
- 반복 관측 및 선명도 기반 후보 선택 단위 테스트
- 제한된 프레임 버퍼 단위 테스트
- 전체 단위 테스트, 디버그 빌드, Android 테스트 컴파일, lint 실행
- 실제 번호판 인식률과 CameraX 3개 UseCase 동시 지원 여부는 실기기 검증 항목으로 남긴다.
