## 현재 남은 사항

- Galaxy S25에서 FHD 1920x1080 30fps+AAC, HD 1280x720 30fps 무음, SD 720x480 30fps+AAC 출력을 확인했다.
- 실내에서 GPS 요청만 시간 초과될 때 이미 수신한 네트워크 위치까지 버리던 문제를 수정했고, MP4 `location`/`location-eng` 태그 기록을 재검증했다.
- 3버튼 내비게이션의 가로 화면에서 녹음 스위치가 시스템 뒤로 버튼과 겹치던 문제를 수정했고, 모든 조작부가 안전영역 안에 있는 것을 확인했다.
- 같은 녹화에서 이벤트를 두 번 요청한 경우 두 파일이 각각 저장됐고, 이벤트 후 1분을 기다리지 않고 녹화를 중지해도 짧은 영상으로 완료됐다.
- 30분 연속 녹화 발열, 권한 거부, 저장공간 부족, 실제 블루투스 기기 페어링과 모든 지원 키 검증은 아직 남아 있다.
- Play 업로드용 `1.0.2` (`versionCode 3`) AAB를 기존 업로드 키로 서명했다: `app/release/app-release.aab`. 기존 서명본과 SHA-256 인증서 지문이 일치하는 것을 확인했다.
- 음성 제거 Media3 처리 엔진과 기존 미리보기 화면의 실행 버튼은 연결했으며 기존 파일을 `_MUTED.mp4`로 변환하는 실기기 검증은 남아 있다.
- 이벤트 MP4를 제출 첨부로 선택했을 때 위치 메타데이터가 제출 위치로 자동 입력되는 전체 흐름 검증은 남아 있다.
- 위 필수 기기 검증을 마치기 전에는 실시간 녹화 기능을 출시 완료로 판정하지 않는다.
