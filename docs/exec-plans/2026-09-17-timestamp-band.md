# 영상·사진 상단 촬영 시각 띠

## 승인된 방향

- 영상 위에 글자를 겹치지 않고, 위쪽에 흰색 여백과 검은 촬영일시를 추가한다.
- 원본 화면을 자르거나 축소하지 않는다. 시간 표시 사본을 별도로 저장한다.
- 촬영 시각 기준이 없는 파일에는 현재 시각이나 파일 수정 시각을 대신 넣지 않는다.

## 적용 범위

- 새로 저장하는 실시간 녹화 이벤트에 적용한다. 기존 갤러리 파일은 변경하지 않는다.
- `DCIM/SafeClip/SC_EVENT_....mp4`: 시간 띠 없는 이벤트 원본 구간.
- `DCIM/SafeClip/SC_EVENT_..._TIMESTAMP.mp4`: 시간 띠 포함 사본. 앱의 저장 결과 URI는 이 사본을 가리킨다.
- 전후 5분 이벤트는 기존 1분 분할을 유지하고, 각 조각마다 원본·사본을 만든다.
- 현재 사진 생성 경로는 영상 프레임 캡처다. 시간 표시 사본에서 캡처하면 해당 프레임의 띠가 JPEG에도 그대로 남는다. 별도 띠를 다시 붙이지 않는다.
- 원본 구간이나 외부 영상에서 캡처한 사진에는 촬영 시각을 추정해 추가하지 않는다. 기존 사진 일괄 변환이나 새 사진 편집 UI는 추가하지 않는다.

## 구현

- `TimestampBandLayout`: 추가 높이와 원본 영역 보존 좌표 계산. FHD 1920×1080은 1920×1160으로 저장한다.
- `TimestampBandPadding`: Media3 프레임 높이를 늘리고 원본을 아래에 배치한다.
- `EventTimestampOverlay`: 상단 여백에만 흰색 비트맵과 고정 sans-serif 글씨를 그린다. 초가 바뀔 때만 다시 그린다.
- `EventTimestampClock`: 각 조각의 첫 프레임 PTS를 실제 녹화 시각 기준에 연결한다. Media3의 누적 PTS를 이중 가산하지 않는다. 표시는 프레임 단위의 녹화 시각이며 외부 시각 인증을 의미하지 않는다.
- `Media3EventClipAssembler`: 원본을 먼저 저장하고 시간 표시 사본을 생성한다. 위치 메타데이터 처리는 양쪽에 유지한다.
- 변환기가 출력 크기를 자동 축소하지 않도록 해상도 fallback을 끈다. 미지원 인코더에서는 사본 실패를 알리고 이미 저장한 원본은 남긴다.
- 사본 저장 실패는 완료로 표시하지 않는다. 임시 파일과 조각 보호는 성공·실패 모두 정리한다.

## 비용과 제한

- 이벤트당 원본과 사본 두 파일을 저장하므로 기존보다 저장 공간과 처리 시간이 늘어난다.
- 시간 띠 영상은 재인코딩되어야 하며, 입력과 픽셀이 비트 단위로 동일한 무손실 사본은 아니다. 원본 구간에는 시간 띠를 넣지 않는다.
- 이전 버전에서 영상 내부에 이미 새겨진 시간은 제거하지 않는다.

## 검증

- 단위 테스트: FHD·세로·SD·홀수 높이의 영역 보존, 파일명 분리, 조각별 시각, 저장 상태 문구.
- Android 테스트 추가: 흰색 띠와 검은 글씨 픽셀, 초 단위 갱신, 합성 영상 원본·사본 저장, JPEG 캡처 시 띠 중복 방지, 시각 미상, 사본 저장 실패 시 원본 보존.
- 이 작업 시점에 연결된 기기 및 설치된 AVD가 없어 Android 테스트의 실제 실행과 GPU·코덱 출력 검증은 미실시다.
- `testDebugUnitTest`: 290개 통과, 실패·오류·건너뜀 0개.
- `assembleDebug`: APK 빌드 통과.
- `compileDebugAndroidTestKotlin`: 최종 테스트 수정 후 재실행 통과. Android 테스트 실제 실행 통과를 의미하지 않는다.
- `lintDebug`: 오류 0개, 경고 68개. 전체 프로젝트의 기존 유지보수 경고는 별도 정리 대상이다.
- 디버그 APK: `app/build/outputs/apk/debug/app-debug.apk`. 기기 설치, 릴리스 AAB 재생성, 커밋·푸시는 이 작업에 포함하지 않았다.
