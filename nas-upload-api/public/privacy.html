SafeClip 개인정보처리방침

시행일: 2026년 8월 13일

SafeClip 운영자(이하 "운영자")는 SafeClip 앱을 제공하면서 이용자의 개인정보를 중요하게 보호합니다. 이 방침은 SafeClip이 어떤 정보를 수집하고 어떤 목적으로 이용하는지 설명합니다.

1. 처리하는 정보와 이용 목적

정보이용 목적
이메일 주소, 표시 이름, 로그인 제공자, Firebase 사용자 식별자회원가입, 로그인, 계정 식별, 제출 내역 연결, 고객지원
블랙박스 영상, 사용자가 첨부한 사진, 파일명·형식·크기교통 상황 또는 위반 의심 장면 검토, 제출 자료 작성, 영상 분석
사고·위반 일시, 위치와 좌표, 신고 유형, 메모, 동의 내역제출 내용 확인, 회사 검토, 신고 보조자료 작성
문의 유형, 문의 내용, 답변, 문의·제출 시각과 처리 상태문의 대응, 제출 진행상태 안내, 서비스 운영
인증 토큰과 최소한의 서버 요청 기록부정 이용 방지, 보안 유지, 장애 대응

외부 저장장치의 파일은 이용자가 폴더와 파일을 직접 선택한 경우에만 확인하거나 전송합니다. 위치 정보는 이용자가 권한을 허용하고 위치 선택 기능을 사용하거나 직접 입력한 경우에만 제출 정보에 포함됩니다.

2. 정보의 보관과 삭제

  • 계정 정보와 제출 정보는 서비스 이용과 검토에 필요한 기간 동안 보관합니다.
  • 앱의 회원탈퇴 또는 외부 삭제 요청이 확인되면 계정과 연결된 정보 및 서버에 저장된 제출 파일을 원칙적으로 30일 이내 삭제합니다.
  • 백업 데이터는 백업 주기에 따라 최대 30일 이내 삭제될 수 있습니다.
  • 관계 법령 준수, 분쟁 처리 또는 부정 이용 방지를 위해 일부 정보를 보관해야 할 때에는 해당 목적에 필요한 최소 범위와 기간 동안 분리하여 보관합니다.

3. 처리 위탁 및 외부 서비스

SafeClip은 서비스 제공을 위해 다음 서비스를 사용합니다. 이용자의 정보를 판매하지 않습니다.

  • Google Firebase Authentication 및 Cloud Firestore: 로그인, 계정 및 제출·문의 정보 저장
  • Google Sign-In: 이용자가 선택한 Google 계정 로그인
  • Kakao Maps 및 주소 검색 서비스: 지도 표시, 주소·장소 검색
  • SafeClip 운영 서버 및 NAS: 이용자가 제출한 영상·사진 저장과 회사 검토

서비스 제공 과정에서 정보가 국외 서버에서 처리될 수 있으며, 각 제공자의 보안 및 개인정보 보호 기준이 적용됩니다.

4. 이용자의 권리

이용자는 앱의 설정에서 회원탈퇴를 요청할 수 있습니다. 앱을 사용할 수 없는 경우에는 SafeClip 계정 삭제 안내를 통해 외부에서도 삭제를 요청할 수 있습니다. 정보 열람, 정정 또는 처리 관련 문의도 아래 이메일로 접수할 수 있습니다.

5. 권한 사용

  • 위치: 지도에서 현재 위치를 확인하거나 제출 위치를 선택할 때 사용합니다.
  • 카메라: 이용자가 증거 사진 촬영 기능을 직접 사용할 때만 사용합니다.
  • 외부 저장장치 파일: Android 시스템 파일 선택 화면에서 이용자가 허용한 폴더와 파일에만 접근합니다.

6. 안전성 확보 조치

운영자는 인증된 사용자와 관리자만 필요한 정보에 접근하도록 제한하고, 전송구간 암호화, 접근권한 관리 및 장애 기록 확인 등 개인정보 보호에 필요한 조치를 적용합니다.
